# CostBase

ฐานข้อมูลราคาวัสดุก่อสร้าง · ค่าขนส่งตาม ว 477 · สถิติราคา
แขวงทางหลวงชนบทขอนแก่น

เว็บ: https://kkn-datahub.github.io/CostBase/

## วิธีขึ้นเว็บ
อัปโหลด **ทุกไฟล์ในโฟลเดอร์นี้** ขึ้น repo `CostBase` (branch `main`, โฟลเดอร์ root)
แล้วเปิด Settings → Pages → Source: Deploy from a branch → main / (root)

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | ตัวแดชบอร์ดทั้งหมด (ไฟล์เดียวจบ) |
| `manifest.webmanifest` | ข้อมูลแอปสำหรับ "ติดตั้งลงหน้าจอโฮม" |
| `sw.js` | ตัวช่วยให้เปิดได้ตอนเน็ตไม่มี (ราคายังต้องต่อเน็ต) |
| `icon-192.png` `icon-512.png` | ไอคอนบนหน้าจอโฮม Android / เดสก์ท็อป |
| `icon-512-maskable.png` | ไอคอนแบบเต็มกรอบ (Android รุ่นใหม่) |
| `apple-touch-icon.png` | ไอคอนบนหน้าจอโฮม iPhone / iPad |
| `favicon-32.png` | ไอคอนบนแท็บเบราว์เซอร์ |

## ติดตั้งลงหน้าจอโฮม
- **Android / Chrome เดสก์ท็อป** — กดปุ่ม "⤓ ติดตั้งลงหน้าจอโฮม" ที่แถบซ้าย
  (หรือเมนู ⋮ → ติดตั้งแอป / เพิ่มลงในหน้าจอหลัก)
- **iPhone / iPad (Safari)** — ปุ่มแชร์ ↑ → เพิ่มไปยังหน้าจอโฮม

## อัปเดตเวอร์ชันใหม่
เปลี่ยนแค่ `index.html` แล้วแก้เลข `CACHE` ใน `sw.js` (เช่น `costbase-v6.1`)
เพื่อให้เครื่องที่ติดตั้งไว้ดึงตัวใหม่ทันที
